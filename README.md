# caiovictormc.github.io

Personal blog built with [Hugo](https://gohugo.io/) and the [Risotto](https://github.com/joeroe/risotto) theme.

## Local development

```bash
# Clone with submodules
git clone --recurse-submodules https://github.com/caiovictormc/caiovictormc.github.io.git

# Run local server
hugo server -D
```

## Deploy

Deployed automatically via GitHub Actions on push to `master`.
